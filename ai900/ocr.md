# OCR:

OCR is a technology that automatically converts visual text in images - scanned docs, images, photos, digital files - to editable, searchable text data

- OCR pipeline:
    - image acquisition and input
    - preprocessing and image enhancement
    - text region detection
    - character recognition and classification
    - output generation and post processing

- Preprocessing and image enhancement:
    - Noise reduction
        - Filtering and image processing algorigthms
        - machine learning models - denoising auto encoders, CNNs
    - Contrast adjustment
        - Classical methods - histogram equilisation, adaptive threshold, gamma correction
        - Machine learning
    - Skew correction
        - correct document rotation:
            - Math techniques: Hough transform, projection profiles, connected component analysis
            - Neural network models - 
    - Resolution optimisation
        - adjusts image resolution to optimal level for character recognition algorithms
- Text region detection:
    - Layout analysis
    - Text block identification
    - Reading order determination
    - Region classification

- Character recognition and classification:
    - Feature extraction
    - Pattern matching
    - Context analysis
    - Confidence scoring
