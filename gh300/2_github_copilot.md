# Interact with CoPilot:

Inline chat:
- Ctrl + i - Windows
- Cmd + i - Mac

- Slash commands:
    - /explain
    - /suggest - code suggestions for selected code snippet
    - /tests - generate unit tests for selected fn
    - /comment - converts comments to code snippet

- Comments to Code : CoPilot uses nlp to convert comments to code

- Multiple Suggestions:
    - Alt + ] windows
    - Option + ] mac 

- Explain this feature - Right Click on code -> CoPilot: Explain This

- Automated test generation - Command Palette -> CoPilot: Generate Unit tests


- Copilot learns from context. Keeping your code well structured and commented helps Copilot provide more accurate and relevant assistance.

- Troubleshooting Github Copilot:
    - Open Log File or Developer: Open Extensions Logs Folder.

Agent mode
Use agent mode when you have a specific task in mind and want to enable Copilot to autonomously edit your code. In agent mode, Copilot determines which files to make changes to, offers code changes and terminal commands to complete the task, and iterates to remediate issues until the original task is complete.


How CoPilot works:
- To be effective with them, you need to provide them background (context) and clear direction (prompts).
