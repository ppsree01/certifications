# Advanced Features:

- Agents:
    - allow to ask questions using a specific context.
    - @terminal - allows to interact with terminal
    - @workspace - aware of your entire workspace
    - @file - focuses on content of a specific file
    - @directory - considers content of specific directory

- Implicit prompts:
    - /fix - fix error on code
    - /doc - add comments at specified or selected code
    - /explain - gets explanation of code
    - /generate - generates code to answer specified question
    - /help - get help on how to use copilot chat
    - /optimise - analyses and improves the runtime of selected code
    - /tests - creates unit tests for the selected code
